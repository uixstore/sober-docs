# Product Badges

From version 3.0, Sober added separated options for product badges. You can find the document for them in [Theme Options > Shop > Product Badges](theme-options/shop.md?id=product-badges).


## Disable all badges

You can find the option to enable/disable all badges in **Customize > Shop > Product Badges**.


## The "SALE" Badge

This badge will be displayed on discounted products. By default, this badge display the amount of percentage that a product is discounted. But you can change it to a fixed text like "SALE". Besides, you can use 2 pattern `{%}` and `{$}` to display the amount of percentage or cost that a product is discounted.


## The "NEW" Badge

There are 2 ways to set a product as new.

1. **Set the number of days which be used to calculate** - You can found the option **Product Newness** in **Customize > Shop > Product Badges**. This option is the number of days a product is set as new, from the published date.

2. **Mark a product as new** - While editing a product, in the **Advanced** tab of **Product Data** box, you will see an option to set a product as new.

![Product set as new](_images/product--new.png)


## The "HOT" Badge

The "HOT" badge will be displayed on featured product. You can learn how to config a featured product in [this documentation](https://docs.woocommerce.com/document/managing-products/#section-20).

If you want to change the badge's text, you can use the option in the theme option panel for it in  **Customize > Shop > Product Badges**.


## The "SOLD OUT" badge

This badge will be displayed on out-of-stocks products. By default, this badge is disabled. Like other badgets, you can change the this badge's text.
