# Exported Slider {docsify-ignore-all}

Even in the [Installation](installation/import-demo.md) section, we showed you how to import the demo content with one click. But when you select a version to import, it will import the slider of selected version only. If you want to use other slider from our demo, you need to import it manually.

## Import a slider

You can found the importing instruction in the plugin's documentation. Please follow it to import an exported slider file. [How to import a slider](https://www.sliderrevolution.com/documentation/new-module-creation#import-zip)
