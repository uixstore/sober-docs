# Portfolio Page Header

Portfolio page header is the page header of the portfolio page. But it is **only availabel for Masonry layout**.


## Change Background Image

You can change the background image of this page header in **Customize > Page Header**. It is the option **Portfolio Page Header Image**.


## Change Text Color

You can change the text color of this page header in **Customize > Page Header**. It is the option **Portfolio Page Header Text Color**. You can select either **Dark** or **Light** color.


## Troubleshooting

1. **Why I can't change the blog page header image on the page that I use for posts page?**

	Because of the Portfolio page is a special page, the option to change it in **Display Settings** meta box won't work with that page. You must set the blog page header image in **Customize > Page Header**. Besides, please make sure you're using the **Masonry** layout for your portfolio.

1. **I don't see the option "Portfolio Page Header Image" in the Customizer**.

	Please make sure you selected **Masonry** layout for your portfolio page in **Customize > Portfolio > Portfolio Page**.
