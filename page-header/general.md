# Page Header General Settings

Page header is the big banner display after the header. You can control the page header in **Customize > Page Header**. All options for it are described in the section [Theme Options > Page Header](/theme-options/page-header.md)


## Toggle Page Header

You can turn on/off page header with the help of option **Show Page Header** in **Customize > Page Header**.

?> **Note**: you can turn on/off the page header on each page. While editing a page, you will see a **Display Settings** meta box bellow the main editor. There is an option that allows you to turn on/off the page header on that page only.


## Toggle Breadcrumb

You can turn on/off page header with the help of option **Show Breadcrumb** in **Customize > Page Header**.

?> **Note**: you can also select to hide the breadcrumb on each individual page. While editing a page, you will see a **Display Settings** meta box bellow the main editor. There is an option **Hide Breadcrumb** that allows you to turn off the breadcrumb on that page only.


## Use Minimal Page Header

![Page Header Minimal](_images/page-header--minimal.png)

Miminal page header has a smaller height without background image. On our demo, we used it for [Shop V2](http://demo.uix.store/sober/shop/?page_header_style=minimal). To use this page header style, you just select it in option **Page Header Style** in **Customize > Page Header**.


## Page Header Parallax

If you are using the normal page header style (not the minimal), you can enable the parallax effect for your page header. It is the option **Page Header Parallax** in **Customize > Page Header**. You can select either _No Parallax_, _Move Up_ or _Move Down_.


## Change Background Image

Sober has options to change the background image of page headers. Sober supports to display different background images on different pages. You can learn more about it later. You can change the background image in **Customize > Page Header** or in each **Product Category** or in each individual page with the help of **Display Settings** meta box.

?> The recommended dimension for this type of image is **1920x600**.


## Change Text Color

In the Customzer of page header, you will found option to change the text color for page headers. It can also be change in each **Product Category** or in each individual page with the help of **Display Settings** meta box.
