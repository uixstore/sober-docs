# Shop Page Header

Shop page header is the page header of shop, product category category and product tag pages.


## Default Background Image

The default shop page header image is the option **Shop Page Header Image** in **Customize > Page Header**. It will be used on shop, product category and product tag pages.


## Change Shop Page Header Image

If you want to change the shop page header image only and keep the default image for product category, product tag pages, you can use the settings **Page Header Image** in the **Display Settings** meta box of the page you're using for your shop.

![Page header image on pages](_images/page-header--page_image.png)


## Change Category Page Header Image

If you want to change the page header image for a special product category page, you can edit that category to change the page header image of it. When you edit a product category, you will see an option **Page Header Image**.

![Page header image on product category](_images/page-header--category_image.png)


## Change Text Color

You can change the text color of this page header in **Customize > Page Header**. It is the option **Text Color**. You can select either **Dark** or **Light** color.

?> This color can be changed for the **Shop** page only with the option **Page Header Text Color** of **Display Settings** meta box of the page you're using for your shop.

?> This color can be changed on each individual **Product Category** page. When you edit a product category, you will see an option **Page Header Text Color**. (see the image above)
