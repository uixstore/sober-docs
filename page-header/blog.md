# Blog Page Header

Blog page header is the page header of blog page (posts page), category page and tag page.


## Change Background Image

You can change the background image of this page header in **Customize > Page Header**. It is the option **Page Header Image**.


## Change Text Color

You can change the text color of this page header in **Customize > Page Header**. It is the option **Text Color**. You can select either **Dark** or **Light** color.


## Troubleshooting

1. **Why I can't change the blog page header image on the page that I use for posts page?**

	Because of the Blog page is a special page of WordPress, the option to change it in **Display Settings** meta box won't work with that page. You must set the blog page header image in **Customize > Page Header**.
