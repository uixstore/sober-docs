# Display Settings

In the [Theme Options](theme-options/customizer.md), we have global settings for layouts, header color, page header,... But Sober also supports customizing these things for each individual page.

When you edit a page, you’ll see this meta box below the content editor:

![Page display settings](_images/page--display-settings.png)

In this box, you will see following sections:


### Site Header

In this section, you can change the style of the site header.

- **Header Background** - Select the header background color. By default, it will use the **Default** value which is set in the Theme Customizer.
- **Header Text Color** - Select the header text color. By default, it will use the **Default** value which is set in the Theme Customizer.


### Page Header

This section contains options for controlling the page header for this page only.

- **Hide Page Header** - Select this option to disable the page header on this page.
- **Page Header Image** - Upload a new page header image for this page. This image will be used instead of the one was set in Theme Customizer. If you don't upload anything, it will use the default page header image - the [Blog Page Header Image](page-header/blog.md)
- **Page Header Text Color** - Select the text color for page header. By default, it will use the **Default** value which i set in the Theme Customizer.
- **Hide Breadcrumb** - Select this option to hide the breadcrumb inside the page header.
- **Hide Page Title** - If the option **Hide Page Header** is selected. You will have this extra option. It allow you to hide the page title.


### Layout

This section contains options for controlling the layout of current page. By default, the layout for this page is set in **Customize > Layout**. But if you want to use a different layout for this page only, you can setup it here:

- **Custom Layout** - Select this option if you want to use a custom layout for this page.
- **Layout** - Select the layout you want to use.
