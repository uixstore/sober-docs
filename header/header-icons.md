# Header Icons

Header icons include: shopping cart, user login, wishlist, search. All options for them are described in the section [Theme Options > Header > Header Icons](/theme-options/header.md?id=header-icons).

## Toggle icons

You can easily toggle as well as order icons on the header. Sober has an option **Header Icons** that allows you to control header icons:

- **Toggle Icons** - click to the "eye" icon to toggle a icon.
- **Order Icons** - drag icons to order them


## Change the Cart icon

To change the shopping cart icon, please follow these steps:

1. Select **Shopping Cart Icon Source**. You can select either **Built-in Icon** and **Upload Image**.
	- **Built-in Icon** - you can select icons which are included in the theme.
	- **Upload Image** - upload your own icon image. With this option, you should prepare 2 images: the first one in the dark color and the second one in the light color.

1. If you select **Built-in Icon**, you just need to pick one icon for the list in **Shopping Cart Icon** option bellow.
1. If you select **Upload Image**, you must upload 2 icon images for your shopping cart icon. Then you can specify the width and height for it if you want. Use can use these settings for make your icon images be ready for retina dislay, like the trick we use for **Retina Logo**.
