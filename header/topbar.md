# Topbar

You can control the site topbar in **Customize > Header > Topbar**. All options for it are described in the section [Theme Options > Header > Topbar](/theme-options/header.md?id=topbar)


## Enable Topbar

In order to enable the topbar on your website, please navigate to **Customize > Header > Topbar** and select the option **Show Topbar**.


## Change background

At this moment, topbar only support to select from 2 background colors: dark or light. It is the option **Topbar Color**.


## Show Topbar Menu

- To have the topbar menu, please ensure you selected **Topbar Layout** option as **2 Columns**.
- Then navigate to **Customize > Menus > Mene Locations** and asign a menu for **Topbar Menu** location.


## Remove Topbar Menu

To remove the topbar menu, plase select **Topbar Layout** as **1 Column**.


## Currency and Language

To have the currency and lanuage switchers on the left side of the topbar, please make sure:

1. The **Topbar Layout** option is set as **2 Columns**.
1. The option **Left Content** value must be **Currency and Language switchers**.
1. The plugin [WPML](https://wpml.org) is installed on your wesbite. It is used for the language switcher.
1. The plugin [WooCommerce Currency Switcher](https://wordpress.org/plugins/woocommerce-currency-switcher/) is installed. It is used for the currency switcher.


## Custom left content

Please set following options as description:

1. The **Topbar Layout** option is set as **2 Columns**.
1. The option **Left Content** value must be **Custom Content**.
1. Enter your content in the **Custom Content** text area. Please note _HTML_ and _Shortcodes_ are allowed.
