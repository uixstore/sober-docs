# Header

You can control the site header layout, style, background,... in **Customize > Header > Header**. All options for it are described in the section [Theme Options > Header > Header](/theme-options/header.md?id=header-1)


## Header layouts

Sober support 6 header layouts. We call them as "Header V1, Header V2,... Header v6". Just select the option **Header Layout** to change it.

- **Option**: Header Layout
- **Section**: Appearance > Customize > Header > Header

![Header layouts](_images/headers.jpg)


## Header background

At this moment, Sober support to select header background color as **White** or **Transparent** only. You can change the header's background color with the option **Header Background**.

- **Option**: Header Background
- **Section**: Appearance > Customize > Header > Header

?> **Note**: the header background can be changed for each page. While editing a page, you can see a **Display Settings** meta box bellow the editor.


## Header text color

After select background color for the header, you should also select the text color. It will help your visitors easier to see the menu, icons on the header. With the help option **Header Text Color**, you can change the text color easily. But please note, this option is only avaiable when you select **Header Background** as **Transparent**. With the **White** backgroud, the text color is set as **Dark** automatically.

- **Option**: Header Text Color
- **Section**: Appearance > Customize > Header > Header
- **Require**: The option _Header Background_ must be _Transparent_

?> **Note**: the header background can be changed for each page. While editing a page, you can see a **Display Settings** meta box bellow the editor.


## Header hover background

If you select **Transparent** as **Header Background**, you will be able to enable or disable the background color of the main header while hovering on it.

- **Option**: Header Hover Background
- **Section**: Appearance > Customize > Header > Header


## Sticky header

Sober supports 2 kinds of sticky header and also allows to disable it. By default, it is disabled. You can select either _disable_, _normal sticky_ or _smart sticky_.

- **Option**: Sticky Header
- **Section**: Appearance > Customize > Header > Header


## Submenu animation

You can disable or select the animation of submenu when hovering on the menu.

- **Option**: Menu Hover Animation
- **Section**: Appearance > Customize > Header > Header
