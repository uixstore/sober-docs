# Footer Copyright

This area is used to display your copyright trademark and footer menu.


## Edit Footer Copyright

You can edit the copyright trademark on in the option **Footer Copyright** of **Customize > Footer**. You can enter any content such as `©2017 Sober`.


## Footer Menu

In order to setup this menu, please go to **Appearance > Menus** and assign a menu for **Footer Menu** location.

![Footer menu](_images/footer--menu.png)


## Add Custom Content To the Right Side

Sober has an option **Footer Right Content** in **Customize > Footer** to add custom content to the right side of the footer. It will be placed next to [Footer Social Icons](footer/footer-socials.md).


## Add Extra Content To Bottom

If you want to add more content at the bottom of site, Sober has an option for it. It is the option **Footer Bottom Content** in **Customize > Footer**. You can enter _HTML_ or _Shortcodes_ there. Besides, you can also select the alignment for it with the option **Footer Bottom Content Alignment**.

You can use this option to display somethings like custom menu, payment logos...

?> **Trick**: you can desgin your content in a page. With the help of Visual Composer Page Builder, you can build your content for the footer bottom easier. Then copy shortcodes which is generated by Visual Composer to this option to save your time.
