# Typography

All typography options are located within their specific **Appearance > Customize > Typography** panel. You can select font family, font size, line height, color...

![Cusomize Typography](_images/customize-typography.png)

## Main

This section contains typography options for the body, links.

![Cusomize Typography Main](_images/customize-typography--main.png)


- **Body** - it is the option for the whole site, like post content, page content,... It will affect to the whole site except special elements.
- **Link** - select the link color.
- **Link Hover** - select the link color when hovered.


## Headings

This section contains typography options for headings, from **Heading 1 to Heading 6**.


## Header

This section contains typograhpy options for menu, sub menu, side menu (menu on header v6) and sub menu of the side menu. If you want to use a text logo, you can found the option for it in [Header > Logo](header/logo.md).

- **Menu** - customize the font of the main menu. It is the **Primary Menu** and **Secondary Menu**
- **Sub Menu** - customize the font of the sub menu
- **Side Menu** - customize the font of the side menu. It is the **Primary Menu** of Header V6.
- **Side Sub Menu** - customize the font of the sub menu which is in the side menu.


## Page Header

This section contains typography options for the page header title and breadcrumb.


## Widgets

This section contains typography options for the widget title.


## Product

This section contains typography options for the product name, short description and other section titles on the single product page.


## Footer

This section contains typography options for the footer copyright content.
