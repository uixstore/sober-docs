# Portfolio

![Customize Portfolio](_images/customize-portfolio.png#alignright)

This section contains sections which have options for controlling the display of portfolio page and single project page.


## Portfolio Page

![Customize Portfolio Archive](_images/customize-portfolio--portfolio.png#alignright)

This section contains options for the portfolio page. It is the archive page of projects.

- **Portfolio Filter** - display the project filter. It filter products by **Portfolio Type**.
- **Portfolio Style** - select the layout of your portfolio page.

	- **Classic** - this is the demo of it: http://demo.uix.store/sober/portfolio/
	- **Full Width** - this is the demo of it: http://demo.uix.store/sober/portfolio/?portfolio_style=fullwidth
	- **Masonry** - this is the demo of it: http://demo.uix.store/sober/portfolio/?portfolio_style=masonry


## Project Page

![Customize Portfolio Single](_images/customize-portfolio--project.png#alignright)

This section contains options for the single project page.

- **Social Share** - enable or disable the social sharing for a single project.
- **Single Navigation** - enable or disable the single project navigation.
- **Next Link Text** & **Prev Link Text** - enter the text for the navigation.
