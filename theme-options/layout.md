# Layout

![Cusomize Layout](_images/customize-layout.png#alignright)

The Layout section contains options for the site layout. You can select either: no sidebar, sidebar left or sidebar right. It allows to change the layout of following pages:

- **Blog** - the default layout for blog pages like blog, category, tag.
- **Post** - set the layout of single post pages.
- **Page** - set the default layout of pages. In each page, you will have other options to overide this option.
- **Shop** - set the default layout WooCommerce's pages like the shop page, product category pages, product tag pages, etc.


## Blog Layout

The **Default Layout** option is used for the blog page, category, tag and other pages. It is also used for your custom content pages. For example, if you use a plugin to add custom content type (like Events), this option will be used for all event pages.


## Post Layout

The **Post Layout** option is used for the single blog post only.


## Page Layout

The **Page Layout** option is used for pages.

!> **NOTE** - For pages, this option can be overrided in each page. Please see the [Page Display Settings](page/display-settings.md) section for more detail.


## Shop Layout

The **Shop Layout** option is used for the shop page, product category, product tag pages. Please note that it **is not used on single product** page. The layout of single product page is fixed as no sidebar.
