# Footer

![Customize Footer](_images/customize-footer.png#alignright)

This section contains sections and options for controlling layout and content of the footer.

- **Footer Layout** - controls the footer layout and background.
- **Footer Content** - manages the footer extra content.
- **Footer Widgets** - controls the footer widgets area.
- **Footer Instagram** - controls the display of the Instagram feed on footer.
- **Footer Main** - control main elements of the footer like the copyright text, footer custom content.

## Footer Layout

![Customize Footer](_images/customize-footer--layout.png#alignright)

This section contains options for footer layout and background.

- **Footer Wrapper** - select the footer container's width. You can select to display footer content in a boxed or full-width layout.
- **Background** - select the footer background like Dark, Light or custom color.


## Footer Content

![Customize Footer](_images/customize-footer--content.png#alignright)

This section contains options for the footer extra content area.

- **Enable Footer Content** - enable the extra content area.
- **Enable "Go To Top" button** - enable the "go to top" arrow icon on the footer.
- **Footer Extra Content** - enter the custom content for the footer content section. HTML and shortcodes are allowed.


## Footer Widgets


![Customize Footer](_images/customize-footer--widgets.png#alignright)

This section contains options for the footer widgets area.

- **Enable Footer Widgets** - enable/disable footer widgets area on footer. After enable this option, you need to add widgets to Footer Widgdet areas.
- **Footer Widgets Layouts** - select layout for this area. You can choose either 2, 3 or 4 columns layout.


## Footer Instagram

![Customize Footer](_images/customize-footer--instagram.png#alignright)

This section contains options for the Instagram feed that will be displayed above the main footer.

- **Enable Instagram Feed** - enable the Instagram photos feed.
- **Instagram Access Token** - The Instagram token to get photos from your Instagram account -  [How to get Instagram Access Token](misc/instagram.md)


## Footer Main

![Customize Footer](_images/customize-footer--main.png#alignright)

This section contains options for main section of the footer area.

- **Footer Copyright** - enter the copyright text for the site footer.
- **Footer Right Content** - adds extra content on the right site of footer, right beside the footer social icons.
- **Footer Bottom Content** - enter the custom content to display bellow the footer copyright.
- **Footer Bottom Content Alignment** - select the alignment of footer bottom content which is entered in previous option.
