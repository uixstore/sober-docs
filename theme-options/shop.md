# Shop

![Customize Shop](_images/customize-shop.png#alignright)

This panel contains sections which have options that helping you control the shop display, product display... We will have a separated tutorial for controling the WooCommerce plugin and related plugins bellow.


## General

![Customize Shop](_images/customize-shop--general.png#alignright)

This section contains options for controling commons elements, features for your store.

- **Ajax Open Cart Modal** - enable this option if you want to automatically open the cart modal after successfully added a product to the cart.
- **Added to Cart Notification** - turn on/off the notification that will appear when a product was added to the shopping cart successfully.



> [!NOTE]
> You can also set a product as new by an extra option on each product. That option in **Advanced** tab when you edit it.


## Catalog

![Customize Shop](_images/customize-shop--catalog.png)

This section contains options for controling elements on the shop page.

- **Shop Toolbar** - enable or disable the shop toolbar. The shop toolbar is the one which contains tabs, grid selector and the filter.
- **Product Tabs** - select the tab types from: Groups, Categories or Tags
- **Products Tab Groups** - select what tabs you want to use. It only appearce when you select **Groups** for option **Product Tabs**.
- **Number Of Categories** - enter number of top categories will be used for tabs. It only appearce when you select **Categories** for option **Product Tabs**.
- **Tags** - enter tags you want to use as tabs, separate by commas. It only appearce when you select **Tags** for option **Product Tabs**.
- **Product Filter** - enable or disable the filter toggle icon in the shop toolbar.
- **Show Hover Thumbnail** - enable or disable the secondary image when hover on the product image.
- **Hide Out Of Stock Price** - Hide the price of products which are out of stock.
- **Hide Star Ratings** - Hide rating stars on the product catalog pages.
- **Product Columns** - select the default columns for product grid on the shop page. Rememeber it only the default columns. Vistors can change it for yourself with the help of shop toolbar.
- **Products Per Page** - set how many products you want to display on a page.
- **Navigation Type** - select the navigation type: Numeric or load more button or Infinity scroll.


## Product

![Customize Shop](_images/customize-shop--product.png#alignright)

This section contains options for controling the layout and elements on the single product page.

- **Single Product Style** - select single product layout.
- **Product Gallery Auto-Height** - turn on/off the auto-height effect for the product gallery slider. It will be helpful if your products images are not in the same dimension.
- **Product Image Lightbox** - turn on/off the product lightbox. Lightbox is a feature that opens your image or images against a dark backdrop, shining a light on them, similar to a real-life photo lightbox.
- **Product Image Zoom** - turn on/off the the zoom feature for product images. This is helpful to get a closer and quick look at some products that might have intricate details that aren’t clear in their normal image in your store.
- **Product Toolbar** - you can enable/disable the product toolbar which contain the breadcrumb and navigation to the next/previous product. With this option enabled, you can also select to only navigate to the next/previous product in the same category with the current product.
- **Product Share** - select what social sharing icon you want to use.
- **Extra Content** - adds extra content at the bottom of every product short description, bellow the button. Shortcodes and HTML are allowed.
- **Upsell Products Carousel** - this option is usefull if you want to display a carousel of upsell products bellow the main product data.
- **Related Products Carousel** - enable/disable the carousel for the related products section.

## Product Badges

![Customize Shop](_images/customize-shop--badges.png#alignright)

This section contains following options that help you control the product badges.

- **Product Badges** - enable/disable all product badges.
- **Sale Badge** - enable a sale badge for on-sale products. If you enable this badge, you will be able to change the badge text format as percentage or fixed text. You can also use some shortcode like {%} or {$} to display the discounted amount. You can also change the color of this badge.
- **New Badge** - display a "NEW" badge for products. If you enable this badge, you can set the option **Product Newness** as the number of days a prodcut will be keep as a new product, from the date it is published. Besides, you can also set an individual product as a new product with the option in the **Advanced** tab when you edit a product. Like other badges, you can control the badge text and color too.
- **Featured Badge** - display a "HOT" badge for featured products. You can edit the badge text and color.
- **Sold Out Badge** - display a "SOLD OUT" badge for out-of-stock products. You can change the badge text and color too.


## Quickview

![Customize Shop](_images/customize-shop--quickview.png#alignright)

This section contains options of the product quick view modal.

- **Product Quick View** - enable or disable the product quick view modal.
- **Show Quick View When** - select whenever the quickview appear.
- **Quick View Details Link** - enable this option to add a link of product page at bottom of the quickview modal.
