# Blog

![Customize Blgo](_images/customize-blog.png#alignright)

This section contains options for controling the display of both blog and single post pages.

- **Post Header** - select what elements you want to show on the post header of single post page. Click on the "eye" icon to toggle an element or drag it to change the order.
- **Post Navigation** - enable or disable the post navigation. It is the "Next Post/Previous Post" section bellow the post content.
- **Author Box** - toggle the author box which is the section bellow the post content. This box is used to present the information of current post author.
- **Related Posts** - enable or disable the related posts on the single post page.
- **Blog Layout** - select the blog layout, Grid or Classic (list).
- **Show Category List** - enable to show the list all categories inside the page header of blog page.
- **Excerpt Length** - enter the length of post excerpt on blog page. It is the amount of words.
