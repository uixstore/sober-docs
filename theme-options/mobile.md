# Mobile

![Customize Mobile](_images/customize-mobile.png#alignright)

This panel contains sections which have options for controlling the responsive display of your site.

- **Menu**
- **Shop Catalog**
- **Product**
- **Header**


## Header

![Customize Mobile Header](_images/customize-mobile--header.png#alignright)

This section contains options for the site header on mobile.

- **Topbar** - display the topbar on mobile devices. By default, the topbar is disabled on mobile.
- **Header Icon** - allow you to change the icon on mobile header from the shopping cart to others like the wishlist icon.
- **Cart Counter Badge** - display a product count badge beside the shopping cart icon on header. By default, it is disabled.


## Menu

![Customize Mobile Menu](_images/customize-mobile--menu.png#alignright)

This section contains options for the mobile menu.

- **Close Icon** - adds a close icon to the mobile menu. By default, it disabled and visitors can click outside the menu to close it.
- **Mobile Menu Width** - adjust the mobile menu panel width.
- **Mobile Menu Search** - enable to show a search form in the mobile menu. It will display on the top.
- **Search For** - select what the search form will look for. By default, it will look for all content types: posts, pages, products, portfolio,...
- **Mobile Menu Top** - select extra elements on the top of mobile menu. They require you to install extra plugins which are recommened and supported by the theme.
- **Mobile Menu Bottom** - select exta menu items at the bottom of mobile menu.


## Shop Catalog

![Customize Mobile Shop](_images/customize-mobile--shop.png#alignright)

This section contains option for the shop page on mobile.

- **Show Buttons** - enable to show add-to-cart button and add-to-wishlist button for products on mobile. By default, it is disabled.


## Product

![Customize Mobile Shop](_images/customize-mobile--product.png#alignright)

This section contains option for product page on mobile.

- **Product Gallery Display** - select the layout of the product gallery on mobile
