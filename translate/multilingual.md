# Multilingual

This theme is fully compatible with WPML plugin, the most famous plugin for building multilingual websites. Below you will find documentation for using WPML plugin with Sober. If you’ve purchased WPML and have any questions or issues, please check the links below.

- [WPML Plugin](https://wpml.org/) - The highly recommended plugin to manage multi-lingual sites
- [WPML Forum Support](http://wpml.org/forums/forum/english-support/) - If you bought WPML then you get free support from their amazing team
- [Translating Widgets](http://wpml.org/2011/03/howto-display-different-widgets-per-language/) - Tutorial recommended by WPML team for translating widgets
- [Translating Theme Options](https://wpml.org/documentation/getting-started-guide/translating-theme-options/) - Toturial for translating theme options
- [Translating MailChimp Form](https://wpml.org/documentation/related-projects/mailchimp-for-wordpress-multilingual/) - Tutorial for translating the MailChimp form.
